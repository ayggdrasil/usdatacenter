## GitHub Pages 공개 배포 안내 (agair1600@gmail.com)
1. GitHub에서 새 Public 저장소(예: `us-datacenter-atlas`)를 생성합니다.
2. 이 패키지의 `index.html`, `README.md`, `.github/workflows/deploy-pages.yml`을 업로드(또는 push)합니다.
3. 저장소 상단 **Settings** → **Pages** → **Build and deployment**에서 `GitHub Actions`(또는 `Deploy from a branch` -> `main` / `/ (root)`)를 선택하면 즉시 공개 웹서비스 URL(`https://<username>.github.io/us-datacenter-atlas/`)로 배포됩니다.
